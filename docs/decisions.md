# 关键设计决策

记录「为什么这样设计」。运行机制见 [mechanisms.md](mechanisms.md)，模块划分见 [architecture.md](architecture.md)。

- **零构建多文件：注入顺序即依赖 + `__h2x` 命名空间**：不引打包器；每文件一 IIFE 挂载模块，service-worker 的 files 数组即依赖拓扑序；split.js 零依赖使 algo-check.cjs 可整文件加载回归。

- **按需注入而非静态 content_scripts**：SheetJS 体积大，避免所有页面常驻开销；activeTab 权限利于商店审核。

- **下载走后台 chrome.downloads**：页面 CSP（如 ERP 后台）拦截 blob: 下载且静默失败；扩展 downloads API 不受页面策略限制，失败时仍回退 blob。

- **UI 全部 Shadow DOM + 内联样式**：不注入 CSS 文件，`all:initial` 阻断页面样式污染。

- **虚拟采集用「DOM 引用判定 + 相邻窗口重叠合并」**：引用相同 = 窗口没变（非虚拟误报 / 渲染未完成）直接跳过；后缀/前缀匹配消除窗口重叠区重复，同时保留合法重复行。

- **genToken 代际令牌**：异步采集时用户退出/重选，令牌使旧任务回调失效。

- **列拆分用「四通道 + 纯函数」**：采集时一次取齐，默认导出走 merged 通道与 v1.2 一致；blocks 保留块级元素边界使双行格能按行拆而块内空格不拆；applyColumnSplits 不碰 DOM 可离线回归。

- **列筛选用「排除集 + 输出列布局」**：无记录 = 全列导出（零回归）；`columnLayout()` 与 `applyColumnSplits()` 共用短路条件与段数算法，过滤列号严格对齐。

- **列格式只存「数字」且以原列为基准**：`aoa_to_sheet` 对字符串一律写文本，文本即默认无需记录；拆分新列与原列同源，格式随原列继承；`formatColumns()` 复用筛选保留判定，筛选后列号不错位；数值化剥千分位/空白、失败保原文本。

- **自适应列宽用「视觉宽度估算 + 上下限钳制」**：逐列取单元格最大视觉宽度（`isWideCode()` 判 CJK/全角/谚文按 2、半角按 1，内嵌换行取最长行），钳制 \[6, 50]（`wch`）；计满上限即截断返回；在最终 aoa 上计算，列序对齐。

- **持久化用「页面键 + 表指纹」而非 DOM 引用**：DOM 元素无法序列化；表头变 → 指纹不匹配 → 安全降级默认配置；会话内存 Map 仍为唯一真相；local 仅本地不上传，读写失败降级当次会话。

- **图片导出为链接（cell.js）**：img 值从原元素读（`src` 解析后的绝对地址，srcset 兜底 `currentSrc`），按索引对齐替换进克隆；替换先于控件值替换，防串位；链接进入 merged/text/blocks 通道。

- **单元格取值用批量两阶段（cell.js `openBatch()`）**：逐格离屏挂载 = 每格 2-3 次强制回流，万格表格上万次 reflow；写读分组集中执行（克隆先挂游离 holder → 一次挂载 → 两轮集中读 → 集中移除注入节点再集中读）把整表回流降为常数 \~3 次。

- **面板段数计算按参数记忆化（panel.js `segCountOf`）**：每次勾选/键入触发全列全行重扫，万行虚拟快照下卡顿；缓存键 = (列, 模式, 分隔符, 上限) 即全部输入（sample 面板生命周期内不变），无需失效机制。

- **分体表格用「结构片段 + 视觉拼接」双重判定**：只认片段 table（纯表头/纯数据）；视觉拼接（间隙/对齐/宽度/列数）防误并同容器里两个独立表格；自最紧祖先向上首个命中即返回，无需维护组件库类名清单。

- **网格表格识别用组件根特征类（v2.1 `isGridTable`）**：el-table-v2 无 table 元素无法复用 table 系判定，结构探测（role/绝对定位行）脆弱；`div.el-table-v2__root` 是稳定特征类；取行按分区 DOM 序 zip，固定列多分区联动滚动防窗口错位。

- **网格组件适配器注册表（v2.2 `GRID_ADAPTERS`）**：四组件（el-table-v2 / AG Grid / MUI X / Tabulator）差异收敛进 table.js 适配器（`name` + `rootSel` + 五钩子），virtual/main/persist 经分发入口调用，新增组件只加适配器；rootSel 须互不相同（重叠会互相遮蔽，algo-check 有断言）；Tabulator 根类 `.tabulator` 过于通用，另校验 `.tabulator-tableHolder`；行节点复用组件（AG Grid / MUI）经 `rowsSortedByRowIndex()` 数值升序修正；Ant Design Vue Table 原生 table + ant-table 包装类，既有分体配对直接命中。

- **下载文件名 sanitize**：过滤 `/:\*?"<>|` 等非法字符、去首部点号（chrome.downloads 限制）、按所选格式补扩展名（xlsx/csv/json/md/html）。

- **多格式序列化为纯函数模块（format.js）**：与 XLSX 库解耦（仅 xlsx 路径依赖 SheetJS）；输入即导出管线末端的 aoa（拆分/筛选/列格式已应用），全格式列设置行为一致；algo-check.cjs 离线回归转义与结构。

- **CSV 多表拆多文件、json/md/html 汇总单文件**：CSV 单文件无法承载多表（拼接破坏列结构）；JSON 表名键嵌套、MD 二级标题分区、HTML 多 `<table>` 天然支持多表；单表时不带表名后缀。

- **JSON 行对象的列名规则：末行表头 + 列N 补齐 + 重名加序号**：多行表头末行最贴近数据（叶子列名）；空列名/无表头补「列N」保证键完整；重名列作对象键会静默覆盖丢数据，序号后缀保住全部列。

- **MD 单元格竖线转义、换行转 `<br>`**：GFM 表格行以竖线定界、单元格内不允许裸换行；无表头生成「列N」表头行（GFM 必须有表头）。

- **表头行判定：thead/tfoot 行 + tbody 全 th 前导行（v1.11）**：手写表格（内网页/生成报表）常见 `<tr><th>` 无 thead，此前 headerRows=0 会让 json/md/html 把表头当数据（xlsx 全行照写不可见）；全 th 行计为表头后无 thead 表也能得真实列名/表头区。xlsx 输出不变（无规则时 aoa 全行照写），指纹不变（headerCellsOf 无 thead 时本就取首行），虚拟表/分体配对（headerRowCount 独立只认 thead）不受影响；代价：无 thead 表的持久化列键从数字变文本，旧配置不恢复（回落智能预填，一次性）。

- **反馈双通道：hint 留引导/进行时，结果性通知走 toast（v2.0）**：toast 右上角独立堆叠（成功/信息 2.5s 自动消失、错误常驻 + 关闭钮、同屏 3 条上限），进度型经句柄复用同一条；面板与主 UI 共用 deps.toast 注入，不新增内容脚本模块。

- **导出成功保留选择，不自动退出（v2.0）**：自动退出须重选全部表格；保留后 toast 提供「退出」动作 + Esc/取消兜底；交互模型变更 → 主版本号 2.0。

- **虚拟采集可中止，复用 genToken（v2.0）**：采集不可中止时「取消」= 整体退出，误触须重进选择模式重选；「停止采集」只 genToken++ 作废当前任务（collectVirtual 检查点返回 null、finally 还原滚动），选择模式保留可重新点选；与退出共用同一令牌。

- **视觉 token 化 + 深色模式跟随系统（v2.0；视觉设计系统统一扩充）**：颜色/字体/间距/圆角/阴影/控件尺寸集中为 :host CSS 变量，工具栏、弹出菜单与面板两个 `<style>` 共享；浅/深色文字层级收敛为 --c-text/-2/-3 三级 token，color-scheme 同步原生控件（下拉/滚动条）配色、勾选框以 accent-color 取绿色主色，键盘焦点统一走 focus-visible 环形；深色模式经 prefers-color-scheme 覆写 token、无手动开关；prefers-reduced-motion 全局关动效。

- **分页识别「适配器 + 手动指定」两层兜底（v2.5）**：组件分页器（el-pagination / ant-pagination / vxe-pager）特征类稳定、识别即精确到下一页按钮并可读 disabled；自建分页器千差万别——识别不到时进入「指定翻页按钮」子模式（交互与选择模式同构），可用性不依赖识别率；误报无害：认错分页器只会「连续 2 页无新行」自动停止。

- **翻页停止以「行为」而非「结构」为准（v2.5）**：用户指定按钮不一定有规范 disabled 态；核心判定 = 连续 2 页无新行（行签名复用 overlapLen），结构态（disabled/按钮消失）与 500 页硬上限仅作前置短路与防御。

- **翻页按钮的编程式点击豁免采集期拦截（v2.5）**：分页器常为 a\[href]（ant-pagination / jQuery 插件），v2.4 采集期全拦截会吞掉扩展自己派发的翻页点击；豁免仅限 clickPaging 派发期间那一次事件（同步派发、finally 清引用），用户点击拦截规则不变。

- **剪贴板输出复用导出管线，不另起一条（v2.7）**：取数、列拆分/筛选/格式、虚拟与分页快照已全部收敛进 `buildAoa()`；剪贴板只是在「生成文件」之前多一个分流出口（TSV / Markdown 均为现成文本序列化器）；TSV 而非 xlsx 因二进制无法进剪贴板；写入走 Clipboard API → `execCommand` 两级兜底。

- **重置与清空都做显式入口，不复用隐式路径（v2.7）**：「重置」原先只能靠「全不拆 + 全列导出 + 全文本再保存」这条推不出来的路径，故面板加显式「恢复默认」；落盘复用既有「空配置 = 删记录」语义，保存后按「是否仍有配置」切换 toast 口径；「清空已选」复用 `removeSelected()`（快照失效、配置清理、面板草稿同步一处不落），只清选择不退出选择模式。

- **列顺序 = 「原列排列 + 管线最后一步」（v2.8）**：拆分/筛选/格式的输出列号都锚在 `columnLayout()` 上，重排插在中间会让三处列号集体错位；放到最后（格式已作用于值，重排只换位置）与既有链路零耦合。重排粒度取「原列」——段列跟随原列整体移动；含 merges 表禁用（合并区按列号定位，重排会错位）。

- **列顺序用「自然序折叠为 []」表示未调整（v2.8）**：未拖动过的表记录与 v2.7 完全同构（`sanitizeRecord` 兼容旧记录），不因新功能加字段；表头变更后 `order` 未命中的键由 `reorderColumns` 静默忽略、其余按自然序补齐。

- **导出中止复用「代际令牌」模式（v2.8）**：与 v2.0「停止采集」同构（`genToken`）：只作废当前任务、不退出选择模式、已落盘文件不回收；提示统一在 `finally` 发出并带已完成文件数；剪贴板成功路径用 `copied` 排除重复提示。

- **跨设备同步用「local 真相源 + sync 镜像 + updatedAt 合并」（v2.8）**：直接切 sync 会撞配额（单页记录可能 >8KB、总配额 100KB），且老用户数据在 local；改为 local 唯一写入口与真相源、sync 尽力镜像（20 页 LRU + 7KB 单项预检，超限只跳过镜像），注入时两侧按表取 `updatedAt` 更新者合并（相同则先读的 local 胜出）；不新增权限（`storage` 已含 sync），sync 不可用时行为与 v1.7 一致。

- **界面偏好与列设置分键存储（v2.9）**：输出方式与文件名模板是「全局偏好」，与按「页面 + 表指纹」定位的列设置不是一类数据：混进 persist 页记录会让「空配置 = 删记录」的重置语义与偏好记忆互相牵动。故单开 `h2x.prefs` 一键读写，与列设置解耦；文件名只在用户编辑过时落盘（blur 时存），未编辑过则按当前页面标题与时间重新渲染——与 v2.8 前默认命名逐字节一致。

- **文件名模板化 + 单遍占位符替换（v2.9）**：「记住文件名」若只存字面文本，换页面会带出旧标题与旧时间戳；改为 `{title}`/`{date}`/`{time}` 模板后既记住命名习惯，又保留「自动带页面名 + 日期」的价值。单遍正则替换（而非连续 replace）保证标题含 `{date}` 字样时不被二次替换；留空 = 回落默认模板，即「恢复默认」路径。

- **分页总页数取「末页号」而非「总条数 ÷ 每页条数」（v2.9）**：末页号只需读页码项文本（适配器各给一个 `pageSel`），组件与自建分页器通用性最好；按条数换算要解析总条数与页大小两个字段，且 `.el-pagination` 根内还混着页大小选项（10/20/50/100），按根扫数字必然读错。读不到页码项退化为只显示当前页——宁缺勿猜。

- **手动翻页按钮记忆用「页面键 + 表指纹」+ 失效自清（v2.9）**：DOM 元素不可序列化，改存定位器（tag + 非状态特征类 + 序号 + 文本兜底）；表头变更 → 指纹不命中 → 自动失效不误用。按钮点不动时若一直复用会静默退化；故以 `collectPaged()` 的机器可读 `reason`（noNew / tableLost）判定「完全没翻动页面」并清除记忆 + 提示可重新指定，而元素暂时消失（表格重渲染）只回落子模式、保留记忆。

- **虚拟采集窗口衔接用「元素身份优先、内容匹配兜底」（v2.9）**：原实现只按内容求最大公共段（`overlapLen`），「相邻多行内容完全相同」时会把合法重复行误判为窗口重叠而少采（数据 `[X,A,A,A,B]` 的中间窗口丢一行 A）。行节点复用是常态，元素身份是「同一行」的精确证据，故优先用 `refOverlapLen` 求重叠；为防元素跨数据复用误丢行，再用 `refTopsMatch` 做内容二次校验，不符即回落内容匹配；无复用（节点整窗重建）保持 v2.8 行为——三类路径各自安全，零回归。
