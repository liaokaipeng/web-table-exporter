# 产品文档

## 定位

扩展名称：**Web Table Exporter：导出表格**（v2.3 由「HTML2XLSX 表格导出」更名，图标改纯色极简：品牌蓝底 + 白色表格）。v2.6 接入 Chrome 国际化（`_locales`），v2.6.1 提供「中文 | EN」手动开关；v2.7 新增剪贴板输出（TSV / Markdown）与清空已选、列设置恢复默认；v2.8 新增列顺序、导出可中途停止、列设置跨设备同步；v2.9 记住输出方式与文件名模板（`{title}` / `{date}` / `{time}`）、分页进度显示「第 i/N 页」、翻页按钮按页面记住（失效自清），并修复虚拟滚动「相邻多行全同」少采。

面向运营/电商用户：把网页表格（尤其 ERP 后台列表）快速导出为 Excel / CSV / JSON / Markdown / HTML，无需手动复制或截图。典型场景：点三咪 TikTok 促销活动编辑页的商品列表导出。

## 核心用户故事

1. 打开页面想把某表格变成 Excel → 点扩展图标，点表格，导出
2. 页面多个表格想一次导出 → 多选，每个变成一个 Sheet
3. 表格有合并表头 → Excel 保持合并效果
4. 表格是虚拟滚动长列表 → 自动滚动采集全部行
5. 表格含输入框/下拉/开关等控件（一口价等编辑值）→ 导出当前显示/输入的值（规则见 [controls.md](controls.md)）
6. 一列既有输入框又有文字（如「2249 PHP」）想拆两列 → 「列设置」配置，控件值与文本各成一列
7. 一格多个输入框（如秒杀价 + 秒杀库存）想各自成列 → 面板「控件值拆分」，每个控件单独一列（不再顿号合并）
8. 「标题/产品ID」一格两行的列想各自成列 → 面板「按换行拆分」，行内空格不拆
9. 组件库（Element Plus 等）把表头与数据行渲染成两个表格 → 自动识别为一个整体，点一次即选中，导出单个 Sheet
   9a. Element Plus el-table-v2 虚拟化表格（无 table 元素的 div 网格）→ 整体识别，点一次自动滚动采集全部行，固定列（left/main/right 多分区）按视觉列序拼接导出
   9b. AG Grid / MUI X DataGrid / Tabulator 等虚拟化网格（div 结构）→ v2.2 起整体识别与自动滚动采集；AG Grid 固定列分区按视觉列序拼接，行节点复用组件（AG Grid / MUI）按 aria-rowindex 还原视觉行序
   9c. Ant Design Vue Table（原生 table + ant-table 包装类）→ 既有分体配对直接支持，无需特判
10. 想自己命名文件 → 工具栏可改文件名
11. 有些列不需要（操作/日志列）→ 「列设置」取消勾选「导出」，拆分新列同样可单独筛掉
12. 表格里有商品图片 → 单元格导出图片链接（绝对地址），Excel 可直接打开
13. 拆分规则与列筛选下次导出同页面自动生效 → 按「页面 + 表头指纹」记住（本地存储，不上传）；表头变了回落默认，重配即可
14. 价格/数量列想在 Excel 直接求和、订单号/产品ID 保持文本 → 「列设置」把列格式设为「数字」（默认文本）：数字列数值化写入（千分位逗号先剥离，无法解析保持原文本），拆分新列同样生效
15. 导出列宽乱 → 列宽随内容自适应（中文按双宽估算），钳制 6\~50 字符：短列不挤、超长列（如商品标题）封顶换行
16. 想要不只 Excel：给程序处理（csv/json）、贴文档/笔记（md）、浏览器查看（html）→ 导出按钮右侧「▾」下拉切换输出方式（默认 Excel），列设置（拆分/筛选/列格式）全格式一致生效
17. 导出一次想换格式再导 → 导出成功后保留不自动退出，toast 提供「退出」，可连续导出
18. 虚拟滚动采集中发现选错表 → 「取消」变「停止采集」，点击只中止当前采集（不退出选择模式），可重选
19. 表格分页（每页只显示一页数据）→ 选中后点「采集」组件自动逐页翻页采集全部行（v2.5）
   - 分页器识别：Element Plus el-pagination / Ant Design ant-pagination / vxe-table vxe-pager 自动识别；其他分页器点组件后按提示点「下一页」即可（手动指定一次，跨页自动跟随）
   - 起止页：不在第一页时自动先回第一页，采完回到起始页
   - 页数上限：只想采前几页 → 组件中段页数槽填 N（留空 = 全部页）
   - 中途停止：想用已采部分 → 点「停止采集」，已采页保留可直接导出
20. 想手动固定界面语言（中文系统用英文界面、反之亦然）→ 工具栏「中文 | EN」切换，界面与导出文件文案立即切换并记住；再点当前语言恢复跟随浏览器（v2.6.1）
21. 不想落盘，只想贴进飞书/Excel/笔记 → 「▾」下拉选「复制为表格 (TSV)」（贴表格软件）或「复制为 Markdown」（贴文档），点主按钮即写入剪贴板并提示已复制行数（v2.7）
22. 选了好几张表想重选 → 计数旁「✕」一键清空已选（只清选择，不退出选择模式）（v2.7）
23. 之前列设置不想要了想恢复默认 → 面板底部「恢复默认」重置当前表格，保存后清除本页记忆（v2.7）
24. 导出后想把「商品 ID 列放到最后一列」→ 面板左侧手柄拖动调整列序（拆分新列跟随原列），保存后按页面记住（v2.8）
25. 选了几张大表，导出到一半发现选错一张 → 导出期间「取消」变「停止导出」，点击即中止（不退出选择模式，已下载文件保留）（v2.8）
26. 换台电脑还想沿用同一套列设置 → 默认存本机，登录 Chrome 账号时随账号同步到其它设备（v2.8；浏览器提供，不经第三方服务器）
27. 每次导出格式与文件名都想固定 → 选一次就记住（v2.9）
   - 输出方式：下次进选择模式直接用上次选的
   - 文件名模板：编辑一次即记住，写「订单_{date}」即自动带当天日期（`{title}` 页面标题 / `{date}` 日期 / `{time}` 时间），清空回落默认命名
28. 分页表不知道还要翻多久 → 进度显示「第 i/N 页，已采集 M 行」（v2.9；分页器能读出末页号时显示 N，读不到只显示当前页）
29. 自建分页器的「下一页」按钮每次都要手动指定 → 指定一次即按页面记住（v2.9）
   - 复用：下次点「采集全部页」直接复用，提示「已复用上次指定的翻页按钮」
   - 失效清除：按钮没翻动页面（连续两页无新行 / 表格失联）自动清除记忆并提示重新指定
30. 虚拟滚动列表有连续几行内容一模一样（如同一商品的多条同规格记录），怕被去重吃掉 → v2.9 起窗口重叠按行元素身份判定，相邻重复行逐行保留
   - 兜底：内容匹配兜底仍在，仅「整窗重建且相邻多行全同」的极端组合仍可能少采

## 交互规范

### 入口与退出

| 操作 | 行为 |
| --- | --- |
| 点击扩展图标 | 进入选择模式（重复注入由守卫接管：已激活则退出） |
| 再次点击图标 / Esc / 取消按钮 / toast「退出」 | 退出选择模式，清理全部 UI 与监听 |
| 采集中点「停止采集」 | 中止当前采集（不退出选择模式），按钮恢复「取消」 |
| 导出中点「停止导出」 | 中止当前导出（v2.8；不退出模式、已下载文件保留、toast 附已完成文件数），按钮恢复「取消」 |
| 点击已选计数旁「✕」 | 清空全部已选（v2.7；只清选择不退出模式，忙态禁用） |
| Enter | 导出（焦点在工具栏按钮时走按钮默认行为；页面元素持焦点时放行给页面） |

### 选择模式

- 悬浮任意 `<table>`：蓝色高亮框跟随；组件库分体表格（表头/表体两个 table）与 div 网格表格（el-table-v2 / AG Grid / MUI X DataGrid / Tabulator）高亮、点选均整体识别
- 点击表格：选中（绿色覆盖层 + 左上角序号徽标，贴边翻转）；再点取消
- 页面交互可用（v2.4）：非表格点击放行（翻页/筛选/切 Tab 照常）；仅拦截表格点选与链接导航（被拦链接红框高亮 1 秒 + 警示 toast「选择模式下链接已停用，Esc 退出后可跳转」停留 4 秒）；被替换的已选表格自动移除
- 工具栏（底部居中，窄屏自动折行，宽度自适应）：
  - 提示文案：引导/进行时反馈，空间不足先截断
  - 已选计数与清空：计数 + 右侧「✕」圆钮（v2.7，只清选择）；无选中时隐藏，忙态禁用
  - 文件名输入框：可编辑；v2.9 起编辑后跨会话记住为模板（`{title}` / `{date}` / `{time}`），清空 = 默认命名「页面标题_日期-时间」
  - 导出分体按钮（v2.10 起）：主体导出当前格式（默认 Excel）；右侧「▾」下拉选其他输出方式（v2.11 起自绘菜单）——Excel / CSV / JSON / Markdown / HTML + 「复制为表格 (TSV)」「复制为 Markdown」(v2.7)；菜单上移弹出、前项留 8px 间隙，项内留白、悬停高亮、当前项加粗打勾、两组间分隔线；选择即切换并同步主按钮文案；主体与下拉同源启用/禁用，未选表或忙态灰置；v2.9 起选择即存
  - 操作按钮组（列设置、采集组件、导出、取消成组）：列设置未选禁用，已选表有配置时带徽标点；采集组件（v2.5 分页入口，v2.5.2 下拉展开式：主按钮「采集全部页 ▾」开面板——页数上限槽（留空 = 全部页）+ 取消/开始采集，识别不到分页器进「指定翻页按钮」子模式；再点/点外/Esc 收拢，采集中禁用；未选或多选（≥2）禁用，仅单表采集）；导出未选禁用，导出中变「导出中…」（v2.8：此时「取消」变「停止导出」）；取消采集中变「停止采集」
  - 语言开关（v2.6.1）：最右「中文 | EN」分段按钮——默认跟随浏览器，点未激活语言切换并记住，再点恢复跟随；忙态禁用
- 深色模式跟随系统；支持减弱动效（prefers-reduced-motion）

### 列设置面板（列筛选 + 拆分配置 + 列格式）

- 按钮：仅已选 ≥ 1 个表格时可用（与导出同一条件）；已选表存在配置时带徽标点
- 流程：页签切换已选表格（带配置状态点）→ 列清单（拖拽手柄 / 导出勾选 / 列名 / 格式下拉 / 拆分控件）→ 展开子行配拆分模式与参数（行首为原列导出勾选 + 列名，与主行双向同步 + 各新列导出勾选）→ 全列预览（前 3 行实时刷新；不导出列划线灰显、新列绿色标记）→ 保存
- 拆分控件（v2.10.2，单控件）：勾选框即拆分开关（勾选 = 开启并展开配置；取消 = 删规则、恢复原样导出），旁折线 chevron 图标按钮（展开态朝上）只收起/展开子行、**收起后拆分仍生效**；已保存规则重开面板恢复为展开
- 列顺序（v2.8）：每行左侧「⋮⋮」手柄拖动调整导出列序（落点以内阴影标示），手柄聚焦后也可 Alt+↑/↓ 逐位移动；拆分新列跟随原列；列区与预览按调整后顺序渲染；含合并单元格的表格禁用
- 列筛选：每列「导出」勾选（默认全选）；顶部「导出列 已选/全部」+「全选 / 全不选」；原列取消「导出」＝ 该列及其拆分新列整体不导出（子行新列勾选置灰禁用、原状态保留，重勾即恢复），拆分配置仅保留、本次不生效
- 恢复默认（v2.7；v2.8 起回退列顺序）：面板底部按钮，重置当前表格列设置为默认（不拆、全列导出、文本、自然序）并清校验错误态；点「保存」落盘（全空配置 = 删除本页记忆，toast「已清除本页列设置记忆，恢复默认导出」），点「取消」原配置保留
- 列格式：每列「格式」下拉（文本 = 默认 / 数字）；数字列数据行数值化（'1,234' → 1234，表头不动，解析失败保持原文本）；作用于该列及其拆分新列（含合并单元格的表格也可设置，拆分与列筛选仍禁用）
- 三种拆分模式：
  - 控件值拆分：按控件拆为「原名\_控件」（输入框实时值）+「原名\_文本」（页面文字），如「2249 PHP」→「2249」「PHP」；同格多控件各自成列（「原名\_控件1 / 原名\_控件2…」+ 末尾文本列，控件不足行补空）
  - 按换行拆分：格内多行文本按行拆成多列，行内空格不拆
  - 分隔符拆分：按分隔符拆段，新列名「原名1 / 原名2…」；段数上限默认 10（超限并入末段）
- 一列一拆分规则；拆分输出保留原列、新列追加其后（拆错可取消该列「导出」——该列与其新列整体不导出）
- 智能预填（v2.0.1 起默认不拆分）：所有列默认收起；展开后多行文本列预设「按换行拆分」、含控件列预设「控件值拆分」、其余预设「分隔符拆分」但分隔符留空（探测仅作 title 提示）；段数上限默认 10
- 空格分隔符以「␣」显示；Esc 关面板、Enter 保存；面板为对话框（role="dialog"，Tab 焦点圈定面板内）；校验错误就地标红（红框 + 底部「N 项配置有误」）；面板打开时主工具栏导出/取消禁用
- 规则、列筛选、列格式与列顺序保存后持久化（本机 `chrome.storage.local`，v2.8 起镜像到 `chrome.storage.sync` 跨设备同步；按页面 + 表头指纹定位）：取消选择/退出不清空，重选同表自动恢复（「已恢复上次的列设置」）；表头变更指纹不匹配回落预填默认；点「恢复默认」后保存 = 删除记录；含合并单元格的表格禁用拆分、列筛选与列顺序（列格式仍可设置）

### 虚拟滚动表格

点击后自动执行：回顶 → 逐步滚动 → 逐窗口提取行（自动衔接去重）→ 还原滚动位置。期间：

- 工具栏实时显示「已采集 N 行」；按钮禁用、表格点击无响应
- 窗口衔接去重（v2.9）：重叠行按**行元素身份**判定（虚拟列表复用行元素、只换绑数据），故「相邻多行内容完全相同」也逐行保留；节点整窗重建或内容不符时回落按内容匹配（v2.8 行为），不会重复导出
- 可点「停止采集」中止：任务作废、表格不选中、滚动位置还原，选择模式保留
- 完成后 toast「采集完成，共 N 行（含表头）」；虚拟表格须先采集完成才能在列设置面板中取样

### 分页表格（v2.5）

选中后点「采集」组件（留空页数槽即「采集全部页」）：不在第一页先回第一页 → 逐页点「下一页」提取（自动衔接去重）→ 采完回起始页。期间：

- 限定单表：多选（≥2）时禁用，悬浮提示「多表选择时不支持分页采集：请先取消其他表格，仅保留要采集的一个」；取消其他后恢复
- 工具栏显示「第 i 页，已采集 N 行」；v2.9 起能读出末页号时显示「第 i/N 页，已采集 M 行」（N = 末页号，页数上限不改变该显示；读不到总数只显示当前页）；按钮禁用、点击拦截
- 中段页数槽：填 N 只采前 N 页（含会话起点归一后的第 1 页），留空全部页；完成后 toast 附「已采集指定 N 页」
- 可点「停止采集」：保留已采页快照（toast「已停止采集，保留已采集的 N 页」）可直接导出；退出选择模式则整体丢弃
- 完成后 toast「采集完成，共 N 行（含表头）」；提前停止附原因（如「连续翻页无新数据，已停止」）
- 分页器自动识别：el-pagination / ant-pagination / vxe-pager；识别不到时提示「点击『下一页』按钮（Esc 取消）」进指定子模式——悬浮高亮任意元素，点击翻页按钮后采集（跨页自动跟随，页面重建按特征找回）；页数槽同样生效
- 手动指定的翻页按钮按「页面 + 表头指纹」记住（v2.9，本机 `chrome.storage.local`，最多 30 条、超限淘汰最旧）：再次点「采集全部页」直接复用并 toast「已复用上次指定的翻页按钮」；没翻动页面（连续两页无新行 / 表格失联）即清除记忆并提示重指定；按钮暂时不在页面时回落子模式且保留记忆
- 分页表格须先采集完成才能在列设置面板中取样；再次点选复用快照，取消后重选重新采集

### 导出结果

单元格文本：视觉分离的多段文本（换行/连续空格）以单个空格连接，如 `4722 PHP`、`标题 产品ID`；本就连在一起的文本不加空格。图片单元格：导出链接（`src` 解析后绝对地址，srcset 取 `currentSrc`）；无链接图片、video/svg/iframe 为空。文件名：默认 `页面标题_yyyyMMdd-HHmmss`，可编辑，非法字符替换为 `_`，按格式补 `.xlsx`/`.csv`/`.json`/`.md`/`.html`。下载经后台 API（不受页面 CSP 限制），失败回退页面内下载。列设置（拆分/筛选/列格式/列顺序）对全部格式一致生效（列顺序同样作用于剪贴板）。

- **xlsx**：多表 → 多 Sheet（Sheet 名 caption > aria-label > id > 表格N，31 字符截断去重）；合并单元格保留；默认文本写入（订单号/产品ID 前导零与长数字不丢），「数字」列数据行数值化（可直接求和）；列宽自适应——逐列取最大视觉宽度（中文/全角按 2 字符宽，内嵌换行取最长行），钳制 6\~50 字符，空列取下限、超长列封顶换行
- **csv**：RFC 4180 转义、UTF-8 BOM + CRLF，Excel 直开不乱码；多表拆多个文件（带表名后缀，单表不带）
- **json**：单表 = 行对象数组（`[{ "列名": 值, … }, …]`），多表 = 表名键嵌套；列名取最贴近数据的表头行，空列名补「列N」、重名加序号；数字列输出数值
- **md**：GFM 表格（`| 列 | … |` + `---` 分隔），多表二级标题分区；竖线转义、单元格换行转 `<br>`；无表头表格自动生成「列1/列2…」表头行
- **html**：完整 HTML 文档（UTF-8 声明 + 极简表格样式），表头入 thead；多表串接
- 合并单元格不还原（平面数据）；数字列数值化后以文本输出

### 剪贴板输出（v2.7）

- 「▾」下拉末尾两项：**复制为表格 (TSV)**、**复制为 Markdown**（v2.10 前为独立下拉）；选中后主按钮变「复制为…」，点击即写入系统剪贴板（不下载、不动选择），成功 toast「已复制 N 行到剪贴板（可直接粘贴到表格软件）」
- 内容与导出同源：列拆分 / 列筛选 / 列格式 / 虚拟与分页快照全部生效（同一取数与 `buildAoa` 管线），仅最后一步换成「写剪贴板」
- **TSV**：制表符分列、换行分行（无 BOM）；单元格内的制表符/换行破坏列结构，统一替换为空格；多表间以空行分隔
- **Markdown**：复用文档序列化（表名二级标题分区 + GFM 表格）
- 优先异步 Clipboard API；未授权/未聚焦回退 `execCommand`，都失败给常驻错误 toast「复制失败：…」（不静默）

## 已知限制（用户须知）

- 虚拟滚动长列表中，仅「行节点整窗重建（无复用）+ 相邻多行内容完全相同」这一组合仍可能少采（v2.9 起窗口重叠按行元素身份判定，已修复行节点复用组件的情况；分散出现的重复行一直不受影响）
- 分页采集（v2.5）：不还原合并单元格（跨页拼接列号无法稳定对齐）；虚拟滚动 + 分页组合的表格只采集当前页的滚动全量（翻页采集入口对虚拟表格不生效）；手动指定的翻页按钮跨页失联且按特征找不到时中止并保留已采页；自建分页器识别不到时须手动指定一次「下一页」按钮（v2.9 起指定一次即按页面记住，下次自动复用）
- 分页进度与翻页按钮记忆（v2.9）：总页数取分页器末页号——el-pagination / ant-pagination 有，vxe-pager 与自建分页器无（只显示当前页）；页数上限不改变显示的总页数；翻页按钮记忆存本机（不随 Chrome 账号同步，最多 30 条、超限淘汰最旧）并按「页面 + 表头指纹」定位；自建分页器常无「上一页」——复用后从当前页采到末页
- 输出方式与文件名记忆（v2.9）：均为本机偏好（不随 Chrome 账号同步）；文件名模板只在进入选择模式时渲染日期时间（页面停留跨天后仍用进入时的日期）；只记住编辑过的文本，清空输入框即回默认命名
- 含合并单元格的表格不支持列拆分、列筛选与列顺序调整（面板标注禁用，导出保持原样；列格式不受此限）；合并单元格仅在 xlsx 导出还原，csv/json/md/html 为平铺数据
- 列顺序（v2.8）：拆分新列跟随其原列整体移动，不能单独拖到别处；表头变更后已保存顺序里未命中的列按自然序追加（不会丢列）
- 拆分规则、列筛选、列格式与列顺序按「页面 + 表头指纹」记忆：表头变更后不恢复（回落默认需重配）；同页两个表头完全一致的表格共享一份配置；默认仅存本机，登录 Chrome 账号时随账号同步（不经第三方服务器）；同步尽力而为——单页记录超 7KB 不镜像、最多同步 20 页（本机保留 50 页），未登录时行为与旧版一致
- 分体表格按「表头表 + 数据表视觉拼接」识别：两个独立表格若无缝紧贴且列数一致会被视为一个表格；组件库汇总行（show-summary 底部合计表）暂不并入导出
- 单元格导出文本与图片链接，不含图片本身和样式；不支持 iframe 内的表格
- 剪贴板输出（v2.7）：写入依赖页面剪贴板权限（未授权回退 execCommand，两者都失败则报错）；TSV 单元格内的制表符/换行会破坏列结构，写入前统一替换为空格；二进制 xlsx 无法直接进剪贴板，需粘贴表格请用「复制为表格 (TSV)」
- 表格需在当前页面已加载（分页数据需先翻页加载）
