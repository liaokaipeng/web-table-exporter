# 产品文档

## 定位

扩展名称：**Web Table Exporter：导出表格**（v2.3 由「HTML2XLSX 表格导出」更名为 Web Table Exporter，后追加中文说明「导出表格」；定位与功能不变；图标同步改为纯色极简风格：品牌蓝底 + 白色表格）。v2.6 起接入 Chrome 国际化（`_locales`）：商店展示与界面文案随浏览器语言切换，首批支持简体中文与英文（默认中文，中文为开发语言）；v2.6.1 起工具栏提供「中文 | EN」手动语言开关，可覆盖浏览器跟随并记住选择，界面与导出文件内容文案同步切换。v2.7 起输出方式除导出文件外新增「复制到剪贴板」（表格 TSV / Markdown），并补充选择管理（一键清空已选）与列设置显式重置（恢复默认）。v2.8 起列设置新增「列顺序」（拖拽调整导出列序）、导出可中途停止（「停止导出」，不退出选择模式），并把列设置从「仅存本机」扩展为「本机 + 随 Chrome 账号跨设备同步」。v2.9 起记住上次的输出方式与文件名模板（文件名支持 `{title}` / `{date}` / `{time}` 占位符，留空 = 默认命名），分页采集进度显示总页数（「第 i/N 页」），手动指定的翻页按钮按页面记住（下次直接复用，失效自清）；并修复虚拟滚动采集中「相邻多行内容完全相同」时的少采（窗口重叠改按行元素身份判定，见下「虚拟滚动表格」）。

面向运营/电商用户：把网页上的表格（尤其是 ERP 后台列表）快速导出成 Excel / CSV / JSON / Markdown / HTML，无需手动复制粘贴或截图。典型场景：点三咪 TikTok 促销活动编辑页的商品列表导出。

## 核心用户故事

1. 我打开一个页面，想把某个表格变成 Excel → 点击扩展图标，点击表格，导出
2. 页面有多个表格，我想一次性导出 → 多选表格，每个变成一个 Sheet
3. 表格有合并的表头 → Excel 里保持合并效果
4. 表格是虚拟滚动的长列表 → 扩展自动滚动采集全部行
5. 表格里有输入框/下拉/开关等控件（一口价等编辑值） → 导出的是当前显示/输入的值（规则见 docs/controls.md）
6. 一列里既有输入框又有文字（如「2249 PHP」），我想拆成两列 → 「列设置」面板配置，控件值与文本各成一列
7. 一格里放了多个输入框（如秒杀价 + 秒杀库存），我想各自成一列 → 面板「控件值拆分」，每个控件单独一列（不再用顿号合并）
8. 「标题/产品ID」这类一格两行的列，我想标题和 ID 各成一列 → 面板「按换行拆分」，行内空格不拆
9. 组件库（Element Plus 等）把表头和数据行渲染成两个表格 → 自动识别为一个表格整体，点一次即选中，导出单个 Sheet
   9a. 表格是 Element Plus el-table-v2 虚拟化表格（无 table 元素的 div 网格结构）→ 同样整体识别，点一次自动滚动采集全部行，固定列（left/main/right 多分区）按视觉列序拼接导出
   9b. 表格是 AG Grid / MUI X DataGrid / Tabulator 等其他组件的虚拟化网格（div 结构）→ v2.2 起同样整体识别与自动滚动采集；AG Grid 固定列分区按视觉列序拼接，行节点复用的组件（AG Grid / MUI）按 aria-rowindex 还原视觉行序
   9c. 表格是 Ant Design Vue Table（原生 table 元素 + ant-table 包装类）→ 既有分体配对直接支持，无需组件特判
10. 我想自己命名文件 → 工具栏可改文件名
11. 表格有些列我不需要（如操作/日志列），不想导出后再删 → 「列设置」面板取消勾选「导出」，拆分产生的新列同样可单独筛掉
12. 表格里有商品图片 → 单元格导出图片的链接（绝对地址），在 Excel 里可直接打开
13. 我配置过的拆分规则与列筛选，下次再导出同页面时自动生效 → 保存后按「页面 + 表头指纹」记住（本地存储，不上传）；表头变了则回落默认，重新配置即可
14. 价格/数量列导出后在 Excel 里想直接求和，订单号/产品ID 列想保持文本 → 「列设置」面板把列格式设为「数字」（默认文本）：数字列数值化写入（含千分位逗号先剥离，无法解析保持原文本），拆分产生的新列同样生效
15. 导出的 Excel 列宽乱七八糟，窄列挤成一条线、长标题列又太宽 → 列宽随内容自适应（中文按双宽估算），钳制在 6\~50 字符：短列不挤、超长列（如商品标题）封顶换行，打开即可读
16. 我想要的不只是 Excel：数据要给程序处理（csv/json）、要贴进文档/笔记（md）、要直接浏览器查看（html）→ 导出按钮右侧「▾」下拉切换输出方式（默认 Excel），列设置（拆分/筛选/列格式）对全格式一致生效
17. 导出一次后想换格式再导一次（Excel 给同事、CSV 给程序）→ 导出成功后选择保留不自动退出，toast 提供「退出」动作，可连续导出
18. 虚拟滚动采集中发现选错了表 → 「取消」按钮变「停止采集」，点击只中止当前采集（不退出选择模式），可重新选择
19. 表格是分页的（每页只显示一页数据）→ 选中表格后点「采集」组件自动逐页翻页采集全部行（v2.5）：Element Plus el-pagination / Ant Design ant-pagination / vxe-table vxe-pager 自动识别；其他分页器点组件后按提示点击「下一页」按钮即可（手动指定一次，跨页自动跟随）；不在第一页时自动先回第一页，采完回到起始页；只想采前几页 → 组件中段页数槽填 N（留空 = 全部页）；采集中想中途停下用已采部分 → 点「停止采集」，已采集的页保留可直接导出
20. 浏览器语言不合我意，想要手动固定界面语言（如中文系统想用英文界面、反之亦然）→ 工具栏「中文 | EN」切换，界面与导出文件内容文案立即切换并记住选择；再点当前语言恢复跟随浏览器（v2.6.1）
21. 我不想落盘，只想把表格贴进飞书/Excel/笔记 → 导出按钮右侧「▾」下拉选「复制为表格 (TSV)」（贴表格软件）或「复制为 Markdown」（贴文档），点主按钮即写入剪贴板并提示已复制行数（v2.7）
22. 选了好几张表后想重新选 → 计数旁「✕」一键清空已选（只清选择，不退出选择模式）（v2.7）
23. 之前的列设置不想要了，想恢复默认 → 列设置面板底部「恢复默认」按钮重置当前表格，保存后清除本页记忆（v2.7）
24. 导出后「商品的 ID 列想放到最后一列」→ 列设置面板左侧手柄拖动调整列顺序（拆分出的新列跟随原列），保存后按页面记住（v2.8）
25. 选了几张大表，导出到一半发现有张表选错了 → 导出期间「取消」变「停止导出」，点击即中止（不退出选择模式，已下载的文件保留）（v2.8）
26. 换台电脑还想沿用同一套列设置 → 列设置默认存本机，登录 Chrome 账号时随账号同步到其它设备（浏览器提供，不经过第三方服务器）（v2.8）
27. 我每次导出的格式都一样、文件名也想固定成一套命名 → 选一次就记住了（v2.9）：下次进选择模式直接是上次的输出方式；文件名编辑一次即记住，写「订单_{date}」这类模板就自动带上当天日期（`{title}` 页面标题 / `{date}` 日期 / `{time}` 时间），清空则回到默认命名
28. 分页表不知道还要翻多久 → 采集进度显示「第 i/N 页，已采集 M 行」（v2.9；分页器能读出末页号时显示 N，读不到只显示当前页）
29. 自建分页器的「下一页」按钮每次都要手动指定一次 → 指定一次即按页面记住（v2.9）：下次点「采集全部页」直接复用并提示「已复用上次指定的翻页按钮」；按钮没翻动页面（连续两页无新行 / 表格失联）会自动清除记忆并提示重新指定
30. 虚拟滚动的列表里有连续好几行内容一模一样（如同一商品的多条同规格记录），怕被去重吃掉 → v2.9 起窗口重叠按行元素身份判定，相邻重复行逐行保留（既有内容匹配兜底仍在，仅「整窗重建且相邻多行全同」的极端组合仍可能少采）

## 交互规范

### 入口与退出

| 操作                              | 行为                                                |
| ------------------------------- | ------------------------------------------------- |
| 点击扩展图标                          | 进入选择模式（重复注入由守卫接管：已激活则退出）                          |
| 再次点击图标 / Esc / 取消按钮 / toast「退出」 | 退出选择模式，清理全部 UI 与监听                                |
| 采集中点击「停止采集」                     | 中止当前采集任务（不退出选择模式），按钮随后恢复「取消」                      |
| 导出中点击「停止导出」                     | 中止当前导出任务（v2.8；不退出选择模式，已下载的文件保留，toast 附已完成文件数），按钮随后恢复「取消」 |
| 点击已选计数旁「✕」                       | 清空全部已选表格（v2.7；只清选择不退出模式，采集/导出/面板/子模式期间该按钮禁用）      |
| Enter                           | 导出（焦点在工具栏按钮上时走按钮默认行为；页面元素持有焦点时 Enter 放行给页面，不触发导出） |

### 选择模式

- 悬浮任意 `<table>`：蓝色高亮框跟随；组件库分体表格（表头/表体两个 table）与 div 网格表格（el-table-v2 / AG Grid / MUI X DataGrid / Tabulator）高亮、点选均以整体识别

- 点击表格：选中（绿色覆盖层 + 左上角序号徽标，贴屏幕边缘时徽标自动翻内侧）；再点取消

- 选择模式下页面交互可用（v2.4）：非表格点击放行给页面——翻页、筛选、切 Tab 等操作照常进行（可先翻页加载分页数据再继续选表）；仅拦截两类点击：表格点选（选中/取消）、链接导航（防误触跳转丢失选择会话——被拦链接就地红框高亮 1 秒 + 右上角警示 toast「选择模式下链接已停用，Esc 退出后可跳转」停留 4 秒）；翻页/刷新后被替换的已选表格自动从选择中移除

- 工具栏（底部居中，窄屏自动折行——折行各行两端贴边不留左右空洞，内容宽度自适应：单行恰好包住、超出上限才折行，中英文观感一致）：提示文案（引导/进行时反馈，空间不足先截断文案）、已选计数、清空按钮（v2.7：计数右侧「✕」圆钮，一键清空全部已选——只清选择、不退出选择模式；无选中时隐藏不占位，采集/导出/面板/子模式期间禁用）、文件名输入框、导出按钮（v2.10 起为分体按钮：主体导出当前格式、默认 Excel；右侧「▾」下拉打开菜单选择其他输出方式（v2.11 起为自绘菜单——原生 select 弹层在部分浏览器内容贴边、且无法定制内边距）——Excel / CSV / JSON / Markdown / HTML 五种导出格式，末尾追加两项剪贴板输出「复制为表格 (TSV)」「复制为 Markdown」(v2.7)；下拉嵌在原导出按钮位置、与之拼为一体；菜单上移弹出、与前项留 8px 间隙，与「采集全部页」面板同款圆角/描边/阴影，项内左右留白、悬停高亮、当前项加粗打勾，文件格式与剪贴板两组间以细分隔线区分，深浅色随 token；选择即切换，主按钮文案同步——导出模式「导出 X」、复制模式「复制为…」；主体与下拉启用/禁用同源，未选表或忙态整体灰置，菜单在失效时自动收拢；v2.9：输出方式与文件名跨会话记住——输出方式选择即存（下次进选择模式恢复同一项），文件名编辑后记住为模板（`{title}` 页面标题 / `{date}` 日期 / `{time}` 时间，输入框 title 有说明），清空 = 回落默认命名「页面标题_日期-时间」）、操作按钮组（列设置、采集组件、导出、取消成组——折行时整组下移不孤立；列设置未选时禁用，已选表中存在配置时带徽标点；采集组件（v2.5 分页采集入口，v2.5.2 重构为下拉展开式：主按钮「采集全部页 ▾」点开分页采集设置面板——页数上限输入槽（留空 = 全部页）+ 取消/开始采集，识别不到分页器时进入「指定翻页按钮」子模式；再次点击按钮、点面板外或 Esc 收拢，采集中禁用主按钮并收拢）未选或多选（≥2）时禁用（仅支持单表采集，多选时悬浮提示原因；识别到组件分页器直接采集，识别不到进入「指定翻页按钮」子模式）；导出未选时禁用，导出中变「导出中…」防误点（v2.8：此时「取消」变「停止导出」，仅中止本次导出）；取消采集中变「停止采集」）、界面语言开关（v2.6.1：最右侧「中文 | EN」分段按钮——默认跟随浏览器语言，点未激活语言切换并记住，再点当前手动语言恢复跟随；采集中/导出/面板/子模式忙态禁用，切换后提示与按钮等就地换语言）

- 深色模式跟随系统（无手动开关）；支持减弱动效（prefers-reduced-motion）

### 列设置面板（列筛选 + 拆分配置 + 列格式）

- 「列设置」按钮：仅已选 ≥ 1 个表格时可用（与导出按钮同一启用条件）；已选表中存在配置时按钮带徽标点

- 面板流程：页签切换已选表格（页签带已配置状态点）→ 列清单（每列一行：拖拽手柄 / 导出勾选 / 列名 / 格式下拉 / 拆分控件）→ 展开拆分后子行配置模式与参数，子行行首显示原列的导出勾选 + 列名（与主行同一状态、两处双向同步），其后「新列：」列出各新列独立导出勾选 → 最终输出全列预览（原列 + 新列完整结构，前 3 行实时刷新；不导出列划线灰显、新列绿色标记）→ 保存

- 拆分控件（v2.10.2，单控件）：一个勾选框 + 一个图标按钮——勾选框即拆分开关（勾选 = 开启拆分并展开配置；取消勾选 = 删规则、该列恢复原样导出，勾选框悬停提示此语义），勾选框旁折线 chevron 图标按钮（两条边组成，非实心三角；展开态朝上、收起态朝下）只收起/展开配置子行、**收起后拆分仍生效**（预览与导出照常，只是看不到配置；未拆分时该图标隐藏）；已保存的拆分规则重开面板时恢复为展开显示。此前「取消拆分 | ▴收起/▾展开」两个同权重文案按钮易混淆，且「取消拆分」不可逆

- 列顺序（v2.8）：每行左侧「⋮⋮」手柄可拖动调整导出列序（拖到目标行上半 = 插到其前、下半 = 插到其后，落点以内阴影标示），手柄聚焦后也可 Alt+↑/↓ 逐位移动；拆分出的新列跟随其原列整体移动（不单独移动）；列区与预览均按调整后的顺序渲染（预览即所得）；含合并单元格的表格禁用（合并区按列号定位，重排会错位）

- 列筛选：每列最前有「导出」勾选（默认全选）；展开拆分后子行展示各新列的独立导出勾选；顶部工具条显示「导出列 已选/全部」并提供「全选 / 全不选」快捷按钮；原列取消「导出」＝ 该列及其全部拆分新列整体不导出（子行新列勾选置灰禁用、原勾选状态保留，重新勾选导出即恢复），拆分配置仅保留、本次导出不生效

- 恢复默认（v2.7；v2.8 起一并回退列顺序）：面板底部按钮，把当前表格的列设置重置为默认（拆分全部收起、全列导出、文本格式、列序回自然序）并清掉面板内该表的校验错误态；沿用面板「保存才生效」语义——点「保存」落盘（空配置 = 删除本页记忆，toast 改口径「已清除本页列设置记忆，恢复默认导出」），点「取消」则原配置原样保留

- 列格式：每列行末「格式」下拉（文本 = 默认 / 数字）；数字列导出时数据行数值化写入 Excel（'1,234' → 1234，表头行不动，无法解析的值保持原文本）；作用于该列及其拆分新列（含合并单元格的表格也可设置，拆分与列筛选仍禁用）

- 三种拆分模式：

  - 控件值拆分：该列按控件拆为「原名\_控件」（输入框实时值）+「原名\_文本」（页面文字），如「2249 PHP」→「2249」与「PHP」；同格多个控件各自成一列（「原名\_控件1 / 原名\_控件2…」+ 末尾文本列，控件数不足的行补空）

  - 按换行拆分：格内多行文本（如「标题/产品ID」双行格）按行拆成多列，行内空格不拆

  - 分隔符拆分：按分隔符把文本拆为多段，新列名「原名1 / 原名2…」；段数上限默认 10（可改，超限并入末段）

- 一列一拆分规则；拆分输出中原列一律保留、新列追加其后（拆错可直接取消该列「导出」——此时该列与其新列整体不导出）

- 智能预填（v2.0.1 起默认不拆分）：所有列默认收起不拆分（避免打开面板即改变导出结构）；多行文本列展开后预设「按换行拆分」，含控件的列展开后预设「控件值拆分」，其余纯文本列预设「分隔符拆分」但分隔符默认留空（探测结果仅作按钮 title 提示，需手动填写）；段数上限默认 10，均可改

- 空格分隔符以「␣」标记显示；面板内 Esc 关面板、Enter 保存；面板为对话框（role="dialog"，Tab 焦点圈定在面板内）；校验错误就地标红（输入框红框 + 底部「N 项配置有误」汇总，重新输入即清除）；面板打开时主工具栏导出/取消禁用

- 规则、列筛选、列格式与列顺序保存后持久化（本机 `chrome.storage.local` 为主，v2.8 起镜像到 `chrome.storage.sync` 随 Chrome 账号跨设备同步；按页面 + 表头指纹定位）：取消选择/退出不清空，重选同表自动恢复（提示「已恢复上次的列设置」）；表头变更后指纹不匹配则回落智能预填默认；点「恢复默认」后保存 = 重置（删除记录）；含合并单元格的表格禁用拆分、列筛选与列顺序（列格式仍可设置）

### 虚拟滚动表格

点击后自动执行：回顶 → 逐步滚动 → 逐窗口提取行（自动衔接去重）→ 还原滚动位置。期间：

- 工具栏实时显示「已采集 N 行」；按钮禁用、表格点击无响应（防误操作）

- 窗口衔接去重（v2.9）：相邻两次采样的重叠行按**行元素身份**判定（组件库虚拟列表滚动时复用同一批行元素，只换绑数据），因此「相邻多行内容完全相同」也会逐行保留；节点整窗重建（无复用）或引用重叠内容不符时回落按内容匹配（v2.8 行为），不会重复导出

- 采集中可点「停止采集」中止：任务作废、表格不选中、滚动位置还原，选择模式保留可重新点选

- 完成后右上角 toast「采集完成，共 N 行（含表头）」

- 虚拟表格须先采集完成才能在列设置面板中取样

- v2.1 起支持 Element Plus el-table-v2 虚拟化表格（div 网格结构）；v2.2 扩展至 AG Grid / MUI X DataGrid / Tabulator（适配器注册表，新增组件只加适配器）：同样点击一次自动采集；带独立固定列分区时各分区联动滚动（el-table-v2 多分区、AG Grid 左固定分区），导出列按视觉顺序（固定列在前）拼接；行节点复用的组件（AG Grid / MUI，窗口滚动时 aria-rowindex 重新分配、DOM 序非视觉序）按 aria-rowindex 还原视觉行序；Ant Design Vue Table 原生 table 结构经分体配对直接支持

### 分页表格（v2.5）

选中表格后点「采集」组件（留空页数槽即「采集全部页」）执行：不在第一页先回第一页 → 自动逐页点「下一页」逐页提取（自动衔接去重）→ 采完回到起始页。期间：

- 采集目标限定单表：多选（≥2 个已选表）时采集组件禁用，悬浮提示「多表选择时不支持分页采集：请先取消其他表格，仅保留要采集的一个」；取消其他表格后自动恢复可用

- 工具栏实时显示「第 i 页，已采集 N 行」；v2.9 起分页器能读出末页号时显示「第 i/N 页，已采集 M 行」（N = 分页器末页号，页数上限不改变该显示；读不到总数时只显示当前页，不猜数）；按钮禁用、点击拦截（防误操作打断采集）

- 采集组件中段为可见输入框样式的页数槽：填 N 只采集前 N 页（含当前会话起点归一后的第 1 页），留空采集全部页；完成后 toast 附「已采集指定 N 页」

- 采集中可点「停止采集」中止：保留已采集的页写入快照（toast「已停止采集，保留已采集的 N 页」），可直接导出已采部分；选择模式保留。退出选择模式（Esc/取消）则整体丢弃

- 完成后右上角 toast「采集完成，共 N 行（含表头）」；提前停止时附原因（如「连续翻页无新数据，已停止」）

- 分页器自动识别：Element Plus el-pagination、Ant Design ant-pagination、vxe-table vxe-pager；识别不到时提示「点击『下一页』按钮（Esc 取消）」进入指定子模式——悬浮高亮任意元素，点击翻页按钮后开始采集（跨页自动跟随该按钮，页面重建也能按特征找回）；采集组件的页数槽对手动指定的分页器同样生效

- 手动指定的翻页按钮按「页面 + 表头指纹」记住（v2.9，本机 `chrome.storage.local`，最多 30 条、超出淘汰最旧）：同一表格再次点「采集全部页」直接复用该按钮开始采集（toast「已复用上次指定的翻页按钮」），不再进指定子模式；按钮没翻动页面（连续两页无新行 / 表格失联）即清除记忆并提示可重新指定；按钮暂时不在页面（如表格重渲染）时回落指定子模式且保留记忆

- 分页表格须先采集完成才能在列设置面板中取样；再次点选复用快照，取消选择后重选重新采集

### 导出结果（全格式公共）

- 单元格文本：视觉上分离的多段文本（换行/连续空格）以单个空格连接，如 `4722 PHP`、`标题 产品ID`；本来连在一起的文本不加空格

- 图片单元格：导出图片链接（src 解析后的绝对地址，srcset 场景取 currentSrc）；无链接图片、video/svg/iframe 导出为空

- 文件名：默认 `页面标题_yyyyMMdd-HHmmss`，可编辑；非法字符替换为 `_`；按所选格式自动补 `.xlsx` / `.csv` / `.json` / `.md` / `.html`

- 下载：经扩展后台 API（不受页面 CSP 限制），失败自动回退页面内下载

- 列设置（拆分/筛选/列格式/列顺序）对全部格式一致生效（列顺序同样作用于复制到剪贴板）

### 剪贴板输出（v2.7）

- 导出按钮右侧「▾」下拉末尾两项：**复制为表格 (TSV)**、**复制为 Markdown**（v2.10 前为独立输出方式下拉）；选中后主按钮文案变「复制为…」，点击即写入系统剪贴板（不下载文件、不动选择），成功 toast「已复制 N 行到剪贴板（可直接粘贴到表格软件）」

- 内容与导出同源：列拆分 / 列筛选 / 列格式 / 虚拟采集与分页采集快照全部生效（同一取数与 `buildAoa` 管线），仅最后一步从「落盘下载」换成「写剪贴板」

- **TSV**：单元格以制表符分隔、行以换行分隔（无 BOM）；单元格内的制表符/换行会破坏列结构，统一替换为空格；多表之间以空行分隔（粘贴进表格软件即为上下两段）

- **Markdown**：复用文档序列化（表名二级标题分区 + GFM 表格）

- 写入优先用异步 Clipboard API；页面未授权/未聚焦时回退 `execCommand` 兜底，两者都失败给常驻错误 toast「复制失败：…」（不静默）

### xlsx 专属

- 多表格 → 多 Sheet，Sheet 名：caption > aria-label > id > 表格N（31 字符截断，自动去重）

- 合并单元格保留（Excel 原生 merge）

- 单元格格式：默认全部按文本写入（订单号/产品ID 前导零与长数字不丢不变形）；列格式设为「数字」的列数据行数值化写入（可在 Excel 直接求和）

- 列宽：随内容自适应——逐列取单元格视觉宽度最大值（中文/全角按 2 字符宽估算，内嵌换行取最长行），钳制在 6\~50 字符；空列取下限，超长列（如商品标题）封顶换行

### csv / json / md / html 专属

- **csv**：RFC 4180 转义（含逗号/引号/换行的值双引号包裹）、UTF-8 BOM + CRLF 行尾，Excel 直接打开不乱码；多表格拆为多个文件（文件名带表名后缀，单表不带）

- **json**：单表 = 行对象数组（`[{ "列名": 值, … }, …]`），多表 = 表名键嵌套；列名取最贴近数据的表头行，空列名补「列N」、重名列加序号；数字列输出为数值

- **md**：GitHub 风格 Markdown 表格（`| 列 | … |` + `---` 分隔行），多表二级标题分区；竖线转义、单元格内换行转 `<br>`；无表头表格自动生成「列1/列2…」表头行

- **html**：完整 HTML 文档（UTF-8 声明 + 极简表格样式），表头行入 thead，浏览器直接打开即可读；多表串接

- 合并单元格不还原（平面数据）；数字列数值化后以文本形式输出

## 已知限制（用户须知）

- 虚拟滚动的长列表中，仅「行节点整窗重建（无复用）+ 相邻多行内容完全相同」这一组合仍可能少采（v2.9 起窗口重叠按行元素身份判定，已修复行节点复用组件的该情况——组件库虚拟列表普遍复用行节点；分散出现的重复行一直不受影响）

- 分页采集（v2.5）：不还原合并单元格（跨页拼接列号无法稳定对齐）；虚拟滚动 + 分页组合的表格只采集当前页的滚动全量（翻页采集入口对虚拟表格不生效）；手动指定的翻页按钮跨页失联且按特征找不到时中止并保留已采页；自建分页器识别不到时须手动指定一次「下一页」按钮（v2.9 起指定一次即按页面记住，下次自动复用）

- 分页进度与翻页按钮记忆（v2.9）：总页数取分页器渲染出的末页号——el-pagination / ant-pagination 有，vxe-pager 与自建分页器无此字段（只显示当前页）；页数上限不改变显示的总页数；翻页按钮记忆存本机（不随 Chrome 账号同步，最多 30 条、超出淘汰最旧）并按「页面 + 表头指纹」定位（表头变更即不命中）；自建分页器常无「上一页」按钮——复用后从当前页开始采集、结束停在末页（想采全量可先手动回到第 1 页）

- 输出方式与文件名记忆（v2.9）：均为本机偏好（不随 Chrome 账号同步）；文件名模板只在进入选择模式时渲染日期时间（页面停留跨天后仍用进入时的日期，与 v2.8 前默认命名行为一致）；只记住编辑过的文本，清空输入框即回到默认命名

- 含合并单元格的表格不支持列拆分、列筛选与列顺序调整（面板标注禁用，导出保持原样；列格式不受此限）；合并单元格仅在 xlsx 导出还原，csv/json/md/html 为平铺数据

- 列顺序（v2.8）：拆分出的新列跟随其原列整体移动，不能单独拖到别处；表头变更后已保存的顺序里未命中的列按自然序追加（不会丢列）

- 拆分规则、列筛选、列格式与列顺序按「页面 + 表头指纹」记忆：表头变更后不恢复（回落默认需重配）；同页两个表头完全一致的表格共享一份配置；默认仅存本机，登录 Chrome 账号时随账号同步到自己的其它设备（不经第三方服务器）；同步为尽力而为——单页记录超 7KB 不镜像、最多同步 20 页（本机保留 50 页），未登录时行为与旧版一致

- 分体表格按「表头表 + 数据表视觉拼接」识别：两个独立表格若无缝紧贴且列数一致会被视为一个表格；组件库的汇总行（show-summary 底部合计表）暂不并入导出

- 单元格导出文本与图片链接，不含图片本身和样式；不支持 iframe 内的表格

- 剪贴板输出（v2.7）：写入依赖页面剪贴板权限（未授权时回退 execCommand，两者都失败则报错）；TSV 单元格内的制表符/换行会破坏列结构，写入前统一替换为空格；二进制 xlsx 无法直接进剪贴板，需粘贴表格请用「复制为表格 (TSV)」

- 表格需在当前页面已加载（分页数据需先翻页加载）
