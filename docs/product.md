# 产品文档

## 定位

面向运营/电商用户：把网页上的表格（尤其是 ERP 后台列表）快速导出成 Excel，无需手动复制粘贴或截图。典型场景：点三咪 TikTok 促销活动编辑页的商品列表导出。

## 核心用户故事

1. 我打开一个页面，想把某个表格变成 Excel → 点击扩展图标，点击表格，导出
2. 页面有多个表格，我想一次性导出 → 多选表格，每个变成一个 Sheet
3. 表格有合并的表头 → Excel 里保持合并效果
4. 表格是虚拟滚动的长列表 → 扩展自动滚动采集全部行
5. 表格里有输入框/下拉/开关等控件（一口价等编辑值） → 导出的是当前显示/输入的值（规则见 docs/controls.md）
6. 一列里既有输入框又有文字（如「2249 PHP」），我想拆成两列 → 「拆分列」面板配置，控件值与文本各成一列
7. 「标题/产品ID」这类一格两行的列，我想标题和 ID 各成一列 → 面板「按换行拆分」，行内空格不拆
8. 我想自己命名文件 → 工具栏可改文件名

## 交互规范

### 入口与退出

| 操作 | 行为 |
|---|---|
| 点击扩展图标 | 进入选择模式（重复注入由守卫接管：已激活则退出） |
| 再次点击图标 / Esc / 取消按钮 | 退出选择模式，清理全部 UI 与监听 |
| Enter | 导出（焦点在按钮上时走按钮默认行为） |

### 选择模式

- 悬浮任意 `<table>`：蓝色高亮框跟随
- 点击表格：选中（绿色覆盖层 + 左上角序号徽标）；再点取消
- 选择模式下页面点击被拦截，不触发跳转/操作（工具栏自身除外）
- 工具栏（底部居中）：提示文案（含状态反馈）、已选计数、文件名输入框、导出按钮（未选时禁用）、取消按钮

### 拆分列面板

- 「拆分列」按钮：仅已选 ≥ 1 个表格时可用（与导出按钮同一启用条件）
- 面板流程：选表格（Sheet 序号下拉）→ 列清单（表头名，控件列/多行列带徽标）→ 改模式/参数 → 前 3 行拆分前后预览实时刷新 → 保存
- 三种模式：
  - 控件值拆分：该列拆为「原名_控件」（输入框实时值）+「原名_文本」（页面文字），如「2249 PHP」→「2249」与「PHP」
  - 按换行拆分：格内多行文本（如「标题/产品ID」双行格：标题一行、产品ID一行）按行拆成多列，行内空格不拆
  - 分隔符拆分：按分隔符把文本拆为多段，新列名「原名1 / 原名2…」；段数上限可选（超限并入末段）
- 一列一规则；原列一律保留（新列追加其后，拆错可直接删列）
- 智能预填：多行文本列默认勾选并预设「按换行拆分」；含控件的列预设「控件值拆分」但不勾选（由用户确认）；其余纯文本列探测分隔符预填（默认不勾选），均可改
- 空格分隔符以「␣」标记显示；面板内 Esc 关面板、Enter 保存；面板打开时主工具栏导出/取消禁用
- 规则存内存，导出时生效；取消选择该表时规则同步删除

### 虚拟滚动表格

点击后自动执行：回顶 → 逐步滚动 → 逐窗口提取行（自动衔接去重）→ 还原滚动位置。期间：
- 工具栏实时显示「已采集 N 行」
- 按钮禁用、表格点击无响应（防误操作）
- 完成后显示「采集完成，共 N 行（含表头）」
- 虚拟表格须先采集完成才能在拆分面板中取样

### 导出结果

- 多表格 → 多 Sheet，Sheet 名：caption > aria-label > id > 表格N（31 字符截断，自动去重）
- 合并单元格保留（Excel 原生 merge）
- 单元格文本：视觉上分离的多段文本（换行/连续空格）以单个空格连接，如 `4722 PHP`、`标题 产品ID`；本来连在一起的文本不加空格
- 文件名：默认 `页面标题_yyyyMMdd-HHmmss`，可编辑；非法字符替换为 `_`；自动补 `.xlsx`
- 下载：经扩展后台 API（不受页面 CSP 限制），失败自动回退页面内下载

## 状态反馈文案

| 状态 | 文案 |
|---|---|
| 默认 | 点击选择表格（可多选） |
| 采集中 | 虚拟表格采集滚动中… 已采集 N 行 |
| 采集完成 | 采集完成，共 N 行（含表头），2.5 秒后恢复默认 |
| 拆分保存 | 拆分规则已保存，导出时生效（2.5 秒后恢复默认） |
| 导出成功 | 已开始下载…（0.6 秒后退出选择模式） |
| 生成失败 | 导出失败：<原因>（红色） |
| 采集失败 | 采集失败：<原因>（红色） |

## 已知限制（用户须知）

- 虚拟滚动的长列表中，整行内容完全相同且相邻出现的重复行可能少采（分散出现的重复行不受影响）
- 含合并单元格的表格不支持列拆分（面板标注禁用，导出保持原样）
- 拆分规则仅在本次选择模式内有效，退出后清空（不持久化）
- 组件库把表格拆成多个 `<table>`（固定表头/固定列布局）时需分别选择
- 单元格只导出文本，不含图片和样式
- 不支持 iframe 内的表格
- 表格需在当前页面已加载（分页数据需先翻页加载）
