MUI X DataGrid 虚拟化表格测试页

复刻 MUI X DataGrid（v6/v7）渲染结构：无 <table> 元素，div + ARIA role 模拟表格，垂直滚动容器为 .MuiDataGrid-virtualScroller。固定列（pinned）为同行 sticky cell，无独立分区。行节点复用：滚动窗口移动时节点的 aria-rowindex 重新分配、 DOM 顺序与视觉顺序无关（本页刻意将 DOM 序倒置注入，导出正确性完全依赖按 aria-rowindex 排序）。共 300 行数据，其中第 1、101、201 行内容完全相同（模拟合法重复行），导出应全部 保留。
预期：悬浮/点击表格任意位置均应整体识别为一张表；点击后自动滚动采集全部行； 「一口价」列 input 为 JS 属性设值，导出须读实时值；「发货仓」select 同理。
